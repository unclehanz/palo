First install

  1. Tap Download for Android.
  2. Open the downloaded file. If Android asks, allow installs from your browser (only once).
  3. Tap Install, then open PALO!

Updates

After the first install the game updates itself. It checks for a new version when it starts, downloads it in the background, and asks to restart. You only need this page again if the game says Please update the app.
